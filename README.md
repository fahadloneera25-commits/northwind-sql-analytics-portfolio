# Northwind SQL Practice & Portfolio

Hi, I'm Fahad. I use this repo to store my SQL practice queries and mini-projects as I build my data analytics skills.

My goal is to get comfortable answering real business questions—like tracking sales, checking product performance, and looking at customer orders—using SQL Server (T-SQL) and the Northwind database.

## Setup
* Microsoft SQL Server (T-SQL)
* SQL Server Management Studio (SSMS)
* Northwind Database

## Folders
* 01_Fundamentals/ - Basic SELECT, filtering with WHERE, sorting, and dealing with NULLs.
* 02_Aggregations_and_Data_Cleaning/ - GROUP BY, HAVING, CASE statements, and cleaning up dates or text.
* 03_Joins_and_Set_Operations/ - Combining tables with INNER, LEFT, and SELF joins, plus UNION.
* 04_Subqueries_and_CTEs/ - Writing nested queries, EXISTS, and CTEs to break down harder problems.
* 05_Window_Functions/ - Ranking rows, running totals, and comparing periods using LAG and LEAD.
* 06_Advanced_SQL_and_Optimization/ - Views, stored procedures, indexes, and checking execution plans.
* 07_Business_Case_Studies/ - Longer queries answering full business questions from start to finish.

Each .sql file has the business question at the top, my query, and a short note on what the numbers show.
